# Local data contract

`synthetic_sales.csv` is generated by `make_demo_data.py` with NumPy seed 2026.
It contains no sampled, anonymised or otherwise derived real retailer records.
The generator uses arbitrary values to exercise the views. Its deliberately
repeated date/store transaction totals are a test design choice.

Required CSV columns:

| Column | Expected content |
|---|---|
| `date` | One daily date, with no time-of-day component |
| `store_nbr` | Store identifier |
| `family` | Product-family identifier; not an SKU count |
| `state`, `city`, `store_type` | Store attributes, constant per store within the file |
| `sales` | Finite sales measure; meaning/units supplied in metadata |
| `onpromotion` | Non-negative promotion count/indicator; positive means a promotion row |
| `transactions` | Non-negative transaction count, with separately declared grain |
| `dcoilwtico` | Oil-value field; may be missing, units must be declared |

The expected sales key is `(date, store_nbr, family)`. Duplicate keys are rejected
because their meaning cannot be recovered safely from this project. `year`,
`month`, `week` and `day_of_week` are derived from `date` rather than required in
the CSV. An extra old export-index column is harmless but is never treated as a
sales field.

Example metadata for a real local file, **to complete only from verified source
documentation**:

```json
{
  "synthetic": false,
  "source": "Describe the authorised source and version here",
  "sales_unit": "source units (unverified)",
  "oil_unit": "source units (unverified)",
  "transactions_grain": "unknown"
}
```

Choose `date_store` only if the source defines daily store totals repeated on
family rows. Their values must agree within each date/store. Choose `sales_row`
only when the counts are genuinely additive at the sales-row grain. The default
`unknown` hides transaction totals. Metadata is a declaration, not independent
proof of source validity or a licence.

To use the original university data, request the two authorised CSV parts and
their dictionary/licence from the course source. Their remote identifiers do not
establish redistribution permission. No network download or unpublished file
is bundled. If concatenating authorised parts, retain the original columns and
check that the parts do not overlap; the app will reject duplicate sales keys.
